# spotify-AI-detector

A plugin that detects music generated by AI on Spotify.

> **Status:** early development. Nothing is implemented yet.

## What it does

Flags tracks and artists on Spotify that are likely AI-generated, so listeners can make informed choices about what they play.

## Planned approach

- Read track/artist metadata from Spotify
- Score each track for likelihood of being AI-generated
- Surface the result in the Spotify UI
